# Code

Welcome to the Code folder of ChrisBox!
The code for ChrisBox was written in the Arduion IDE.

## Content of the PCB folder

- `ChrisBox_Code/` - The code and librarys for the ChrisBox PCB.
- `ChrisBox_Receiver_New_Lib/` - The code for the Receiver ESP via ESP-Now updated to the New ADC Library Output.
- `Nextion_Code/` - The code/program for the Nextion display.
- `Platformio_Project/` - The Arduino Code imported to PlatformIO, for advanced users only.
- `CP210x_Universal_Windows_Driver.zip` - The Driver to use the Onboard UART Converter on Windows for programming the ESP32.

## Flashing the code on the PCB

For flashing both the PCB and the Nextion display, please refer to [BUILDING INSTRUCTIONS](/BUILDING_INSTRUCTIONS.md).
